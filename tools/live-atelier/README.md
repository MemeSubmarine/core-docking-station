# 活画师 · Live Atelier

给画师的 Windows 桌面工作台。用日历排委托，在旁边摆参考图，画画时把窗口收成一枚工时表盘。

**1.7.4 · Windows x64**　[下载单文件启动版](https://github.com/MemeSubmarine/core-docking-station/raw/refs/heads/main/tools/live-atelier/LiveAtelier-1.7.4-Windows-x64.exe)

## 第一次打开

1. 下载并双击 LiveAtelier-1.7.4-Windows-x64.exe。
2. 启动器自动展开完整程序并打开工作台。
3. 需要悬浮计时时，点击右上角「小表盘」。用顶栏切换横屏或竖屏，拖动日历与参考图之间的分隔条调整比例。

运行需要 Windows x64、.NET Framework 4.6.2 或兼容的更新版本，以及 Microsoft Edge WebView2 Runtime。截图文字识别使用 Windows 本机 OCR 和相应的识别语言。

## 从接单到交稿

| 操作 | 入口 |
| --- | --- |
| 建立常接的业务 | 新建订单，填好来源、稿酬、标签和图钉，点「另存为业务模板」。封面支持本地图片和粘贴截图。 |
| 套用或调整模板 | 新建订单顶部点「按照业务模板添加」。要修改已存模板，在「订单」页点「业务模板库」。 |
| 从平台截图录单 | 在订单中导入或粘贴约稿截图，点选识别出的名字与截稿时间，核对后保存。 |
| 摆参考图 | 在参考板导入、粘贴或拖入图片。空白处拖动框选，滚轮缩放视图，右键打开整理或删除菜单。 |
| 查看排期 | 日期格可打开订单与便签。悬停顶栏「最近截稿」可看本月未完成订单。 |
| 记录工时 | 工时页选择个人练习或委托，两类分开累计。悬浮球单击暂停或继续，按住至少 0.75 秒再松开结束本次，拖动可移动球。 |
| 清空计时 | 设置 → 计时记录 → 清空计时。确认后，全部日期的练习和委托工时清零，当前计时结束，番茄钟复位。订单和模板保留。 |
| 导出月报 | 账本里选择月份并导出 XLSX，查看业务来源、稿酬与工时。 |

## 数据和升级

数据保存在当前 Windows 用户的 %LOCALAPPDATA%\ArtistDesk 下。分发给朋友只需发送下载的 EXE。迁移自己的数据时，请在设置中导出备份，再在另一台电脑上导入。导入会替换目的电脑的工作台数据。升级时先退出旧版，再双击新版 EXE。

## 发行内容与验证

启动包包含程序、界面、字体、图标、本机 OCR 脚本、备份助手及第三方许可。首次演示使用内置示意图。回归测试覆盖计时与番茄钟、清空确认、模板保存和套用、日期打卡、参考图选择与排列、横竖布局和关闭偏好。Windows 真机上的摄像头、OCR 识别率、全局快捷键和多屏 DPI 仍需实际设备验证。

删除关联参考图或历史工时的订单时，图片转入自由参考，原工时记录保留。正在计时的订单需先结束记录。
