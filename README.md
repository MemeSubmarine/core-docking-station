# 画师与手书工具

## 活画师 · Live Atelier

Windows 桌面排单与参考图工作台。用业务模板接单，把参考图铺在日历旁，用悬浮表盘记录绘画工时。

**[下载活画师 1.7.4 · Windows x64 单文件启动版](tools/live-atelier/LiveAtelier-1.7.4-Windows-x64.exe?raw=true)**　·　[安装与使用说明](tools/live-atelier/README.md)

直接运行下载的 EXE 打开主窗口。

## 工具目录

| 工具 | 用途 | 入口 |
| --- | --- | --- |
| 时序手记 | 本地记事，识别时间码、日期与纪年，保留原句或单列时间，自定义线型、节点符号、字号与颜色，生成白底 PNG 长图。 | [打开工具文件](tools/timeline-notebook/index.html) |
| 画师委托台历 | 横竖双页月历与参考图板，支持截稿倒计时、订单、便签、自定义图钉和月历贴纸。 | [下载 Windows x64 桌面版](tools/commission-calendar/desktop/CommissionCalendar-Windows-x64.exe?raw=true) · [使用说明](tools/commission-calendar/desktop/README.md) |

下载单个 HTML 文件后用浏览器打开即可离线使用。笔记保存在当前浏览器，可另存为 TXT 备份。
